# aerotools-web

Código de la nueva web de Aerotools.

Se trabaja en la rama `dev`: cada push a `dev` se publica en https://prueba.aerotools.es mediante GitHub Pages (rama `dev`, raíz `/`).
El dominio se define en el fichero `CNAME` (solo en `dev`).
La versión final es el merge de `dev` a `main`, que no se publica aquí (irá a www en otro repo).

El repo es público: nunca subir claves, secretos ni credenciales.
